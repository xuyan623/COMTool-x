# 验证范围

当前交付是首个可运行版本。验证结果以 `verification/` 中实际报告为准。

自动验证覆盖：

- 类型、端口占用、同步回路及原子批量回滚。
- 明确更新 UI、保存重开、只读模式与运行期间的设计限制。
- 串口 `loop://` 的真实 pyserial 收发、反复断开重连。
- ASCII/二进制分包、校验、损坏帧和旧半帧之后恢复。
- TCP/UDP 本机真实 socket 收发；SSH 本机协议会话与终端。
- AI 接口直接创建和编辑两种设计、控件操作、内部截图。
- 原生曲线保留点、暂停/跟随、通道设置与 CSV/PNG/SVG 导出。
- 自定义 Python 协议、CRC、ANSI 屏幕以及外部插件加载。
- 对打包后的 GUI 程序再次运行端到端检查。

原版与新版本的图表比较脚本见 `tools/plot_benchmark.py`。比较使用同一数据流、通道数、时间窗、绘图区尺寸；记录实际重绘、CPU 与界面事件间隔。离屏 Qt 测量不能代替真实显示器和显卡上的长期表现，数据应与测试条件一同阅读。

需要实机验证：

- 实际 USB 转串口、RTS/DTR 与硬件流控、拔插重连。
- 真实网络、远程 SSH 主机与密钥环境。
- 显示缩放、多显示器和长时间高数据率运行。

软件回环和本机网络检查不代表这些硬件行为已验证。

## 本次实测

2026-10-25，Windows x64。源码行为测试 28 项通过；源码与便携 GUI 的本机 API 端到端流程通过，覆盖前述 TCP/UDP/SSH、软件串口、设计、控件、导出与截图。源码目录报告在 verification/source/report.json、verification/packaged/report.json，便携包中汇总为 verification/source.json、verification/packaged.json。

图表压力条件：每通道 1000 点/秒，10 秒窗口，1200×650 绘图区，10 ms 一批；预载每通道 10000 点，再输入 4 秒。后台系统负载未严格控制。以下是离屏绘制事件，不能作为显示器帧率或实机长期性能承诺。

| 实现与绘制设置 | 通道 | 输入保留点数 | 重绘事件/秒 | 心跳间隔 P95 |
|---|---:|---:|---:|---:|
| 原版，2px 抗锯齿 | 8 | 112000 | 0.44 | 3043.32 ms |
| COMTool-x，2px 抗锯齿 | 8 | 112000 | 1.77 | 1170.39 ms |
