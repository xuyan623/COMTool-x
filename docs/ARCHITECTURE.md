# 架构边界

## 长期设计原则

本节约束长期开发、插件设计和 AI 协作。具体功能的支持范围以实际实现、运行实例的声明和验证结果为准。

### AI 能够完整协作

AI 应能完成工程创建、功能设计、界面设计、插件配置、运行调试、数据观测、文件操作和结果核验的完整工作流。面向用户的能力应同时具备可发现、可查询、可操作的本地接口。

GUI 与 AI 共用操作入口、校验、权限和运行语义。插件的端口、参数、动作、可读状态和失败原因应明确声明；自绘控件也应支持发现、读取和必要的交互。文件操作接受结构化路径，长任务提供可查询的最终结果。新增功能时同步维护接口、文档、协作技能和验证，使 AI 能够发现并正确使用新能力。

### 引擎统一控制运行生命周期

引擎对运行、暂停、单步、停止和重置拥有最终控制权。所有插件适配引擎的控制，局部播放、计时、采集或后台任务均在引擎允许的范围内推进，并及时响应全局控制。

暂停、停止和重置分别遵循统一语义。重置清空运行状态并恢复工程初值，包括插件内部的未保存运行数据；插件自身的局部控制服从这一规则。

### 功能设计决定行为，界面设计决定呈现

功能设计定义节点、端口、连接、功能参数和初值，是行为的依据。界面设计负责外观、布局和绑定。运行控件通过共同操作入口影响功能；两页之间的同步应显式处理变更，保持功能配置与界面属性各自的职责。

### 插件职责明确，复杂行为通过组合完成

基础插件承担独立、清楚的职责。例如按钮发布简单控制信号，复杂操作由实际负责这些操作的其他插件完成。导线只负责一对一传递；分发、选择、计算和其他数据处理各由相应插件承担。

优先实现清晰可用的核心链路，让复杂性集中在真正拥有该职责的实现中。接口和函数应体现有意义的工作，避免无实际职责的转发层、重复状态和为假设需求预留的扩展结构。

### 工程保存设计，运行数据独立管理

工程保存完整设计、配置、初值、布局、绑定以及设计必需的用户插件代码、模型等资源。外部数据文件的路径可以作为配置保存，数据内容独立管理。

采样、曲线缓存、录制内容、日志、播放进度、执行游标和其他运行历史均不写入工程。录制和导出生成独立文件。打开工程恢复设计与初值，运行、连接设备和发送数据由明确操作启动。

### 信号与时间语义明确

端口的数据类型、单位、更新规则和时间含义应可以查询。一次新发布就是一次更新，同值数据也按既定传播规则处理。控制信号统一采用布尔值，状态判断与动作执行通过端口用途和处理规则明确区分；边沿识别由专门的处理插件承担。

计算调度、数据时间和显示刷新各有明确职责。采样批次保持依赖顺序及同源数据的一致性，普通处理节点由输入更新驱动，自主推进时间的行为由信号源负责。

### 显示与真实运行分离，交互反映真实状态

数据采集和计算的正确性优先于显示效果。绘图抽稀、动画降帧和界面刷新频率只影响呈现；界面观测已有运行结果，显示开销应与计算、通信解耦。

设计预览与运行使用一致的视图和布局规则。控件对操作提供清楚反馈，显示真实的可用、执行中、完成或失败状态。界面编辑手势由设计器统一处理，运行操作通过实际功能入口执行。

### 声明、实现和验证同步演进

插件声明、实际行为、GUI、本地接口、文档和协作技能应保持一致。异步请求的提交与实际执行完成分别核验；原始数据、处理结果和图像证据各自用于证明相应事实。

验证采用真实实现，清楚区分构建检查、离线运行、界面操作和实机结果。已验证的结论应写明适用范围，发现契约与实现不一致时先定位和修正。

## 单工程会话

`core/` 是工程模型、插件声明、类型化数据、采样批次、日志与独立计算线程。普通节点按依赖顺序接收完整输入，同源分支汇合只执行一次。通信节点隔开异步循环；同步环被拒绝。

`plugins/` 包含官方 C++ 通信、协议、数据、数学、曲线、姿态和 ANSI 终端。`IoHub` 在单独线程拥有设备对象；计算线程通过检查过的命令交换数据。接收队列超限会明确报错并暂停，不能用动画降帧掩盖数据丢失。

`app/` 负责同一工程的窗口会话、设置、文件、任务、QML 控制器与本地接口。GUI 和 API 使用同一 `Controller::command`，文件任务和引擎操作通过完成/失败的 job 返回。

`quick/`、`qml/` 是只消费快照的显示和交互。底部引擎栏属于主窗口，工作区标签位于顶部，对象栏和属性栏可收起；页面保留自己的工具。页面唯一，拖出只改变归属窗口，所有窗口共享同一引擎。

## 观测与动画

引擎约每 50 ms 发布不可变运行快照，界面不持有可变节点指针。可见仪表按配置请求更细的数据；每个视图至多有一个未完成请求，隐藏页面不持续请求昂贵数据。

曲线保留原始环形数据，显示按像素抽稀；CSV 导出原始数据，PNG/SVG 导出当前范围。FFT 对实际数据计算，不将抽稀坐标当作源数据。

导线动画采样已有 count/step_count，以低优先级事件请求重画；每条导线最多 64 根代表亮条，每帧有短绘制预算。跳帧按经过时间推进，不积压每包动画。普通暂停冻结，单步只运动经过的导线；速度和密度随观测频率变化，仍保留间隙。计算线程不调用绘图、不等待渲染。

## 本地 Python 扩展

官方功能没有 Python 依赖。用户选定的本地解释器通过 `QProcess` 按需运行 `python/worker.py`，使用独立 UTF-8 行协议。脚本的 print/stderr 接入日志，输出和状态须可序列化；失败调用不提交新状态。超时或结束会话会关闭进程，后续调用按需重建。

用户插件拥有 process(inputs, state) 和可选 action_<name>；QML 只拿到声明视图的 bridge。辅助文件在临时私有包中展开，允许相对导入，卸载时清理命名空间。解释器路径属于本机设置，不进入工程。

## 工程与发布

v3 `.crpj` 使用带类型字节值的 CBOR 与压缩，单文件携带设计、配置、布局、用户插件代码与资源，官方插件记录其 ID。工程格式标识为 corig-project，录制为 corig-recording。保存使用原子替换；只读取 CoRig 文件头，不转换旧工程结构。

发布由 CMake 原生构建和 Qt 官方部署工具生成。便携包不包含 Python 运行环境、个人工程或接口 token；源码归档包含本项目模块与 libssh2。

## 对象、放置与同步

`app/editor_commands.cpp` 管理对象的放置、撤下、图层、独立复制、替换影响和双向同步清单；它与已有命令一起经 `validateProject` 验证后才提交。`placed=false` 的功能节点仍保存配置，但不进入依赖序列或计算线程。待放置视图保留在 `pending` 分支，设计画布和运行界面不渲染该分支。

界面对象保存节点绑定快照，以便删除一页对象后，另一页仍能明确保留、删除或同步重建。快照不能作为界面参数覆盖已有功能配置。`sync.plan` 产生稳定变更键和工程校验值；`sync.apply` 只执行明确勾选的项目，设计变化时要求重新检查清单。新增目标对象总是待放置，重复同步保持 ID、已有位置和层序。

`layout.canvas` 是自由组合的网格画布。`DesignGrid.js` 以整数网格单元计算行、列、网格和分页容器，存档几何也由 `alignUiToGrid` 对齐。容器保留局部自动排版，其他对象可重叠，上方图层优先显示。界面设计由一个统一手势层选择、拖动、调整尺寸和判断容器落点；`UiItem` 负责真实控件渲染。容器的视图占位区域参与落点命中，并显示插入标记。命中测试尊重裁剪边界，允许拖回未被裁剪的画布外对象。运行时只对完整设计作一次等比缩放。

`NodeSurface`、`NodeCapsule` 和 `PortGlyph` 共用卡片外形、分区、公式和端口语义。端口兼容预览遵循实际方向、类型、占用和环路约束。改接先解除旧线，取消时返回输出母体；鼠标跟随只改变界面暂态，成功落位才创建新对象或导线。

端口沿节点两侧纵向排列并撑高卡片，节点旋转后文字保持正向，选中描边覆盖完整轮廓。牵引输出囊泡时，源位置保留同色短线；兼容输入沿凹口高亮，不兼容端口变暗并说明原因，卡片主体亮度保持不变。悬停显示嵌合预览，点击后正式连接。

取出已连接囊泡时旧线立即断开，可以接回原凹口或改接。右键、Esc、点击空白或输出母体短线均取消牵引，返回母体并保持断开。拿着待放置对象或拖动对象时右键取消当前操作；空闲时右键打开快速放置。

对象复制生成新的对象和节点 ID，继承配置、外观及所选子图内部连线；外部连线独立处理。替换保留位置、尺寸、层序和兼容连线，先列出不兼容连线的影响。设计提交进入当前编辑会话的撤销重做历史。

## 界面实现约定

插件视图与容器不显示左上角的外层标题，不保留标题栏占位；名称用于对象栏定位。设计预览与运行复用同一套控件布局，避免容器标题或编辑状态改变内部尺寸。开关采用左右拨动样式，按钮显示实际按下状态；界面反馈来自真实控件与运行状态。

功能节点使用小圆角直边的三段结构：输入为半圆凹口，中间为图形/公式和名称，输出为凸起囊泡。缺少的一端省略，端口名称及英文类型常驻显示，选中描边覆盖完整轮廓。

插件库中间卡片左右展示功能设计与界面预览，以浅色竖线分隔；右侧详情保留两种预览。不适用当前页面的卡片使用黄色边框并给出原因。容器属于界面设计专用分类，插件库不作为工作区标签。
