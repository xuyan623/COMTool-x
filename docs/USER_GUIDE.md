# CoRig 使用手册

[项目首页](../README.md) · [下载](https://github.com/xuyan623/CoRig/releases/latest) · [本地 API](API.md)

## 安装与示例

从 Releases 下载 `CoRig-Windows-x64.zip`，完整解压。


解压完整便携包，双击 `CoRig.exe`。Qt DLL、plugins 和 qml 文件夹需要保留在程序旁。

- `examples/FunctionLab.crpj`：无需硬件，时间源持续驱动正弦、余弦曲线与三维飞机姿态。
- `examples/SerialPlot.crpj`：串口连接、文本收发和 FireWater 三通道曲线。默认 `loop://` 为软件回环；选择实际 COM 口后才连接设备。可在收发框发送 `1,2,3` 验证回环曲线。
- `examples/RecordPlayback.crpj`：软件信号、曲线与姿态的录制回放。一个按钮通过分发同时开始录制和倒计时，到时自动暂停；录制文件由用户另行保存、导入，示例只携带设计。

打开工程不自动运行、连接或发送。底部公共引擎栏始终控制当前工程；F5 调试运行，Ctrl+F5 普通运行，F6 暂停，F10 整图下一步，F11 节点单步，Ctrl+Shift+F5 重置，Shift+F5 结束会话。

底部运行／暂停合并为一个随实际状态切换的图标按钮，调试模式开关与快捷键独立保留。所有插件服从引擎控制；重置也会清空尚未保存的录制和临时导入文件。

暂停保留连接、历史和处理状态；结束会话释放连接；重置恢复工程初值，也会清除只读运行中的临时调参。

```powershell
.\CoRig.exe .\examples\FunctionLab.crpj
.\CoRig.exe --data-dir D:\CoRigData .\examples\SerialPlot.crpj
```

设置、日志和本地连接信息默认写在程序目录；程序目录不可写时用 `--data-dir` 指定可写目录。

## 搭建一个调试工程

1. 在功能设计中打开插件库，添加通信、协议、处理和仪表节点。
2. 从待放置区选择对象，在画布单击放置，按端口方向连接数据流。
3. 在右侧属性栏设置通信、协议、量程和初值。
4. 通过同步按钮检查变更清单，将所需控件加入界面设计，再安排位置、大小和容器。
5. 运行后观察真实数据，按需暂停检查或单步推进，最后保存 `.crpj` 工程。

## 工作区与设计

工作区标签位于顶部，公共引擎控制与状态栏位于底部。功能设计与界面设计都采用左侧对象栏、中间画布、右侧属性栏；两侧可调宽、隐藏并重新展开。对象栏用缩进表示容器层级，上方图层优先显示。

功能设计、界面设计、运行界面和日志各有一个页面实例。标签可排序、拖出、拖回。分离窗口保持精简页头，和主窗口共享同一工程、引擎与连接；默认按聚焦关系切换前后顺序，手动置顶后才保持最上层。插件库入口直接打开唯一独立窗口，再次打开会定位已有窗口。

1. 两页左上角都有独立插件库入口，支持预览功能设计与界面。不适用当前页面的插件会说明原因。容器位于界面设计专用分类，插件库使用独立窗口。
2. 插件库快速添加和跨页同步的新增对象先进入待放置区。空闲时右键快速放置，选择后跟随鼠标、单击落位；拿着对象时右键或 Esc 取消，不创建临时对象。
3. 功能节点分为输入、处理与输出区域，端口名称和类型直接显示。连接前可根据端口提示判断数据方向与兼容性。
4. 点击输出囊泡牵引，源位置留下同色短线；兼容输入高亮，其他端口变暗并说明原因。点击凹口完成嵌合；取出后可接回原凹口或改接。右键、Esc、点击空白或输出母体短线均归还囊泡并断开连接。
5. 支持多选、移动、尺寸调整、复制粘贴、替换和撤销重做；删除或有影响的替换先显示清单。节点空格旋转、导线路径点编辑及调试功能保留。
6. 界面设计采用可设置粒度的方格纸，放置、移动、尺寸和容器内部排列都吸附到同一网格。控件自身不抢设计手势，容器显示插入位置，超出设计范围但仍可见的对象也能拖回。
7. 两页分别提供对应方向的同步图标，每次先显示默认全选的变更清单。新增对象进入目标页待放置区；已有摆放与层序保留；目标页多余对象默认列入删除，可取消勾选保留。
8. 功能设计只编辑通信、端口、运算、量程和初值等功能参数；界面设计只编辑外观与布局。运行界面将整张设计等比缩放，比例不符处留白。
9. 撤下功能节点解除连线、退出计算，但保留对象配置；撤下界面控件退回待放置区，保留对应功能节点。独立复制产生新对象／节点并继承配置外观，外部连线不继承。
10. 保存 `.crpj` 单文件工程。工程包含设计、配置、网格、布局、用户插件和模型资源；官方插件由应用提供。采样、日志、录制内容、播放进度和其他运行历史独立管理，外部录制文件只保存路径引用。

图结构修改需要先暂停；暂停后已有节点保留处理状态。只读模式锁定设计，仍支持连接、发送和临时调参。关闭页面不停止引擎；关闭最后一个窗口时处理未保存修改并结束会话。

## 内置功能

- 串口：收发、流控、RTS/DTR、断线重连与软件回环。
- 网络：TCP 客户端/多连接服务端、UDP 客户端/服务端；原生 libssh2 SSH 密码/密钥认证、主机指纹检查和 PTY。
- 收发：文本/HEX、编码、转义、换行、快捷指令、历史、文件发送/取消与接收记录。
- 协议：命名 ASCII/二进制、FireWater、JustFloat、文本、JSON 与本地 Python 编解码。
- 数据和数学：采样帧、通道提取、分发、通断、选择、常量、时间、定时器、算术/三角、限幅映射、波形、随机、积分微分、平均、低通与多输出表达式。
- 逻辑与时序：与、或、非、与非、或非、异或、同或，及上升沿／下降沿／双边沿触发。控制信号统一为布尔值，按钮每次点击只发布一条 `true`；周期触发和单次倒计时支持外部开始／停止，重复开始重新计时。数据分发默认两路，右栏可调整为 2～8 路。
- 信号录制与回放：单路输入输出、原样直通、开始／暂停合并控制、外部开始／暂停、结束保存与重置；暂停片段拼接，文件使用独立的 `.crrc` 格式。回放提供导入、截断开关、播放／暂停、逐条、进度条和 0.125～16 倍速。原有字节记录仍支持二进制与 HEX 日志。
- 曲线：C++ 原生绘制，左键平移、滚轮缩放、跟随、冻结显示、通道显隐/颜色、FFT、原始 CSV 与 PNG/SVG 导出。冻结显示时采集继续。
- 姿态：极简飞机、STL/OBJ 静态模型，欧拉角/四元数输入、度/弧度、旋转顺序、内禀/外禀、轴映射、参考姿态及相机控制；左键旋转，右键平移，滚轮缩放。不提供姿态融合。
- 终端：ANSI 屏幕控制、颜色、UTF-8 与 SSH 终端尺寸传递。
- 调试：批次/节点单步、执行位置、节点输入输出与耗时、筛选日志及 JSONL 导出。

普通节点由上游新输出触发，同值输出也传播；常量在有消费者时持续就绪，时间源各自定时。导线动画显示实际数据活动，频率影响速度和密度；暂停冻结，单步显示实际经过的导线。动画仅用于观察，实际数据通过曲线、节点状态和导出检查。

回放导入成功后仍实时直通；打开截断开关后保持待播放，点击播放才输出文件数据。截断时拖动进度会立即输出目标记录，暂停或播放结束保持截断，关闭截断恢复实时。右栏指定的默认文件路径随工程保存，运行界面导入仅对本次会话生效。回放只改变输出信号，下游曲线历史、积分和滤波状态各自管理。

## 用户插件与本地 API

用户插件采用 Python 逻辑和可选 QML 视图，在“设置 → 本地 Python 环境”选择本机或虚拟环境的 `python.exe`（3.10+）。程序不携带、不安装 Python，也不自动安装依赖。缺少环境或模块时显示具体错误。Python 代码在独立进程执行，官方功能不依赖该进程。

插件库中“导入用户插件”选择 JSON 声明。可运行示例见 `docs/plugin_examples/gain.json`。插件代码、辅助文件和 QML 资源随工程保存；解释器路径只存本机设置。

GUI 与本地 API 共用同一命令入口。程序仅监听本机，连接信息位于 `<data-dir>/.sessions/api.json`，包含本次实例凭据，请勿共享。子窗口使用同一实例接口。

AI 可以直接编辑功能设计、界面和绑定，查询端口兼容性，设置画布缩放／平移与侧栏，控制窗口及运行调试，读取真实数据和内部截图，再保存重开工程。具名和未命名的 QML 控件均可发现；标准输入会触发实际操作，自绘控件可接收应用内部输入。原生 CLI 的 `--wait` 等待控件发起的后台动作完成。完整调用示例与 94 个命令的实际覆盖报告见 [验证范围](VERIFICATION.md)。

```powershell
.\CoRig-cli.exe api app.state
.\CoRig-cli.exe api registry
.\CoRig-cli.exe api runtime.start --json '{"debug":false}' --wait
```

工程使用独立的 CoRig 文件标识，仅保存 `.crpj` 和 `.crrc` 新格式；不读取旧产品的工程、录制文件或迁移旧布局与控制配置，修改后缀不能转换格式。插件和本地接口采用当前 v3 契约。详见 [API](API.md)、[插件开发](PLUGIN_SDK.md)、[架构](ARCHITECTURE.md)、[验证范围](VERIFICATION.md) 和 [配套 Skill](../skills/corig/SKILL.md)。

## 录制回放操作示例

1. 运行 `RecordPlayback.crpj`，点击“录制 5 秒”。按钮同时启动录制和倒计时，到时暂停。
2. 保存录制为独立 `.crrc` 文件，再在回放控件中导入。
3. 打开“截断”，屏蔽实时输入；点击播放，或使用逐条、进度条与倍速控制。
4. 关闭“截断”恢复实时输入。暂停和播放结束仍保持截断，需要自行切回实时。

工程不包含录制历史。移动工程时，需要同时整理默认回放路径引用的外部文件。完整接口见 [API](API.md)，界面实现约定见[架构文档](ARCHITECTURE.md)。
