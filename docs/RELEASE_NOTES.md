# CoRig 版本说明

[项目首页](../README.md) · [GitHub Releases](https://github.com/xuyan623/CoRig/releases)

## v0.4.0

- 工程 `.crpj`、录制 `.crrc`、插件 `.crpl` 统一使用新的文件扩展名。
- 78 个官方节点外置为逐节点插件包，C++ 和 Python 共用导入、管理和导出流程。
- 插件分类取自文件夹，支持展开/折叠，根目录归“其他”；外部调整重启生效。
- 工程可选择携带全部使用的插件，或只记录依赖；保存选项可随时修改。版本冲突由用户选择。
- 工程插件按树状勾选导出，支持全选、全不选、反选及分类选择，保留目录结构。
- 提供无需主程序源码的 C++ SDK、完整增益示例、标准 Windows 安装程序及按组件更新仓库。
- GUI、AI 接口和配套技能覆盖插件树、批量导出、保存选项、版本选择和维护操作。

原生测试八套通过；独立 SDK 构建与插件专项 38 项、安装更新 14 项通过。安装与更新的本机验收结果见[验证范围](VERIFICATION.md)。安装版正式更新源为 https://xuyan623.github.io/CoRig/updates/windows-x64/，随本次 Release 发布。

## v0.3.0

首个以“联调 · CoRig”名称发布的版本，用可组合的功能设计与界面设计搭建工程调试方案，并支持人与 AI 操作同一个工程。

### 主要能力

- 原生 C++ / Qt Quick 工作台，官方通信、处理、仪表和控制功能无需 Python。
- 功能节点与独立界面设计，支持插件库、双向同步、网格容器、撤销重做及共享引擎的分离窗口。
- 串口、TCP、UDP、SSH，配合文本/HEX、常见曲线协议、JSON 和可选 Python 编解码。
- 实时曲线、FFT、原始数据/图像导出、三维姿态与 STL/OBJ 模型显示。
- 布尔逻辑、边沿识别、数据分发、周期触发与可重新计时的倒计时。
- 原始类型信号录制、暂停拼接、独立文件、逐条与进度跳转及 0.125～16 倍速回放。
- 本地 API 与原生 CLI，共 94 个公开命令，支持设计、运行调试、真实数据、内部截图及 Python/QML 用户插件。
- 三个可直接运行的公开示例：FunctionLab、SerialPlot、RecordPlayback。

### 文件与格式

工程使用 `.corig`，录制使用 `.corigrec`。工程携带设计、配置、用户插件及模型资源；运行数据与录制文件独立管理。

此版本移除了旧产品工程、录制文件、旧布局与控制配置的读取和自动迁移。修改后缀不能转换格式。本地 API 与插件使用当前 v3 契约。

### 下载与使用

- `CoRig-Windows-x64.zip`：完整解压，双击 `CoRig.exe`；需要保留旁边的部署文件。
- `CoRig-source.zip`：对应源码、第三方源码、测试与构建工具。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

可先打开 `examples/FunctionLab.corig` 并启动运行，无需硬件。Python 仅在使用相应扩展时配置。

### 验证范围

七套原生测试和部署程序验收覆盖软件回环、三个示例、工作台、仪表、录制回放及全部 94 个公开命令。验证摘要随便携包提供，具体场景和限制见[验证范围](VERIFICATION.md)。物理串口、远端设备及不同 Windows 机器的表现仍需实机验证。
