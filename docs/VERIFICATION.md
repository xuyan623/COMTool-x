# 验证范围

[项目首页](../README.md) · [使用手册](USER_GUIDE.md) · [构建与发布](BUILDING.md)

本文件记录 CoRig 0.3.0 Windows x64 原生版本的验证范围。原生测试和实际部署验收于 2026-10-29 通过；性能表保留 2026-10-28 的原生版本基线，未作为本次发布的重新测量结果。

## 原生行为与界面

原生测试覆盖 78 个官方节点构造、同源分支汇合、暂停/单步、布尔控制、录制回放、分包协议、原始环形数据与 FFT、模型几何与旋转、ANSI 屏幕，以及实际本地 Python 的超时与重启。

Qt Quick 窗口事件测试覆盖囊泡取出/接回、点击母体归还、取消牵引、快速放置、容器插入、画布外对象拖回、嵌套网格、同步清单、尺寸与删除确认。90°/270° 端区文字边界和容器内部几何也有检查；设计与运行不为外层标题保留空间。

工作台验收通过实际操作检查待放置节点不计算、撤下保留配置、勾选同步及幂等、独立复制、删除清单、属性隔离、指数计算结果和保存重开。窗口验收检查独立插件库、共享引擎、页面回接、普通聚焦与手动置顶。

## 数据、控制与录制回放

软件串口回环验证了每通道 1024 个精确原始采样、显示抽稀、实际 16 Hz FFT、冻结显示时继续采集、原始 CSV 和 SVG 导出。姿态检查验证了度制欧拉角输入导致的实际 90° 旋转。

控制测试覆盖七种逻辑门、边沿识别、2～8 路分发、重复开始重新计时及引擎暂停/重置。录制测试覆盖六类信号原样保存、损坏文件拒绝、取消保存保留原文件、暂停片段拼接和未保存数据重置。

部署程序通过实际控件验证按钮经分发同时开始录制与倒计时、到时暂停、实时直通、独立文件、截断、逐条/进度跳转、倍速及播放结束保持截断。默认文件和临时导入的重置规则、工程不包含录制历史也均已检查。

## AI 接口与用户扩展

本地 API 验收通过真实 HTTP 完成全部 94 个公开命令，报告列出 `covered_commands`，`missing_commands` 为空。范围包括插件发现、端口兼容、批量编辑、同步、绑定、画布与侧栏、窗口、运行调试、真实数据、日志、内部截图、保存重开和退出。

独立 Python/QML 插件使用真实解释器、辅助文件相对导入与日志。未设置 `objectName` 的控件通过自动 handle 被发现；滑块、下拉框、SpinBox、中文文本提交和自绘鼠标操作均检查了实际 Python 状态与输出。原生 CLI 的 `--wait` 验证了控件触发的后台任务完成。

命令覆盖表示每个公开命令至少完成一次成功调用，并结合关键拒绝和结果检查；不等于穷举每种参数或未来第三方插件。自动 handle 在对象销毁或视图重建后需要重新发现。

## 发布完整性

在清除开发 Qt/Python 搜索路径的环境中，部署程序能独立启动。SerialPlot、FunctionLab、RecordPlayback 三个示例无需选择 Python 即可运行，节点间距检查均为空。原生 CLI 可在默认连接记录缺失时恢复发现；关闭另一实例不影响当前工程。

程序、CLI、窗口标题、文件属性、接口、工程与录制文件均使用 CoRig 标识。原生测试确认 `.crpj` 和 `.crrc` 保存与重开正常，旧产品文件即使修改后缀也会被拒绝；CLI 也拒绝缺少 CoRig 产品标识的旧连接记录。

部署包检查确认不含 Python/PySide6 运行时，打开、重开及退出时无 QML 引用、类型或绑定循环错误。正式 Release 附带便携包、对应源码及 SHA-256 校验值。

## 性能基线

以下为 2026-10-28 的本机测量。图中包含 20 条持续就绪的三节点计算链（60 个节点），另有 100 Hz 时间源和实际可见曲线。关闭/开启动画交替各两轮，每轮测量 4 秒。CPU 以一个逻辑核心为 100%，统计整个应用进程时间增量。

| 指标 | 动画关闭 | 动画开启 |
|---|---:|---:|
| 节点执行次数/秒 | 548659.29 | 540663.65 |
| 应用 CPU/单核 % | 120.10 | 131.63 |
| 实际曲线数据 Hz | 101.24 | 99.99 |
| 实际视图送达/秒 | 42.37 | 42.50 |
| 曲线帧间隔 P95/ms | 33.57 | 33.52 |

本机动画开启时吞吐变化 -1.46%，所有轮次 `failed_delta=0`。数据刷新、帧交换和计算计数分别记录，动画定时器触发不作为观测帧。开发环境原始结果为 `verification/native-performance/report.json`，此数据不代表其他机器或未来版本的性能。
