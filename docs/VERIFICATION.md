# 验证范围

本文件描述 2026-10-29 的原生 C++ / Qt Quick 版本及工作台重构验收。旧 Python/PySide6 测试结果不用于本次结论。

## 开发验证入口

- `tools/build_native.ps1 -Test`：构建并运行原生模型、依赖执行、通信及 Qt Quick 手势回归。
- `tests/native/workbench_ui_test.cpp`：囊泡连接与取消、界面菜单、容器插入、画布外拖回、嵌套网格及同步清单的窗口事件测试。
- `tools/native_workbench_check.py`：独立原生实例的同步、复制、属性隔离、保存重开、真实计算与截图检查。
- `tools/native_ui_check.py`：旋转与连线编辑、调试、共享引擎、工作区窗口和插件库检查。
- `tools/native_release_check.py`：移除开发路径后的便携包验收。

## 已验证

- 原生 CTest 七套测试通过：core、editor、workbench_ui、execution、control、recording、io。涵盖 78 个节点构造、同源分支汇合、暂停/单步、布尔控制、录制回放、分包协议、原始环形数据与 FFT、模型几何与旋转、ANSI 屏幕、本地 Python 超时与重启。
- Qt Quick 实际窗口事件回归通过：囊泡取出后接回原凹口、点击母体归还、右键取消持有对象、界面快速放置、拖入容器、画布外对象拖回、嵌套网格、同步清单、尺寸与删除确认。90°／270° 端区文字边界检查通过；设计与运行中容器标题高度均为 0，子控件位置和尺寸相同。
- 26 项实际界面检查通过：横纵排版、唯一插件库子窗口、置顶、页面回接、导线编辑/撤销、调试游标和日志、公共引擎控件，以及顶部横排工作区。共享引擎控制位于底部。
- 独立原生实例及部署程序分别通过 12 项工作台检查：待放置节点不计算、撤下保留配置、勾选同步与幂等、独立复制、删除清单、属性隔离、真实指数计算、保存重开及底部引擎。报告见 verification/native-workbench/report.json 和 verification/native-packaged/workbench/report.json。
- 左右编辑侧栏支持拖至 0 宽度隐藏，并从边缘重新展开；先前已完成实际拖动验证。原有空格旋转、中文输入法预编辑/候选提交、标签拖出/拖回的真实键鼠验证记录保留。
- 18 项仪表/扩展联调通过：软件串口回环的精确采样、显示抽稀、实际 16 Hz FFT、冻结显示仍采集、原始 CSV、欧拉角 90 度、真实 Python 辅助文件相对导入/日志、QML 视图、临时调参/重置及工程重开。
- SSH 使用仅监听本机的真实软件服务器，已验证主机信任检查、密码认证、中文 ANSI 收发和 PTY 尺寸传递；这不代表远端 Linux 设备已验证。
- 7 项实际动画检查通过：频率影响速度/密度、亮条间隙、暂停冻结、继续运动、单步只播放经过的导线、结束清空。

## AI 协作覆盖

已补齐画布精确缩放／平移、侧栏宽度和收起、原生窗口几何和恢复、界面对象外观字段查询、已有视图重新绑定及端口兼容性查询。具名与未命名 QML 控件均可发现，每个实际对象有存活期间稳定的 handle；标准控件赋值执行对应用户操作，自绘控件可通过应用内部 Qt 键盘／指针事件操作。没有系统鼠标移动、操作系统键盘注入或桌面截图依赖。

tools/native_ai_check.py 通过真实 HTTP 完成全部 94 个公开命令的成功调用，覆盖插件发现、批量编辑、双向同步、布局与绑定、窗口、运行调试、数据、日志、内部截图、保存重开和退出。报告逐项列出 covered_commands，missing_commands 为空。普通 Qt 窗口事件回归另验证了画布／侧栏读写和滑块、下拉框、SpinBox、文本提交对真实节点的影响。

独立 Python/QML 插件未给控件设置 objectName。测试通过自动标识操作其滑块、下拉框、SpinBox、中文文本及自定义 MouseArea，逐项检查实际 Python 状态和乘法输出；原生 CLI --wait 等待这些回调产生的后台动作完成。过程使用真实解释器和应用控件，未使用 Mock 或实体设备。源码版报告见 verification/native-ai/report.json；便携版对应报告见 verification/native-packaged/ai/report.json。

命令覆盖表示每个公开命令至少完成一次成功调用，并结合关键拒绝与实际结果检查；不等于穷举每种参数或未来第三方插件。自动 handle 在对象销毁／视图重建后失效，需要重新发现。需要文件路径的操作直接使用工程／节点接口；第三方业务和外部系统动作通过插件声明的 node.action 暴露。
